Kurulum Adımları
1. Testnet Hesabı
demo.binance.com adresinden hesap oluşturun
Email ile kayıt olun ve doğrulayın
10,000 USDT test bakiyesi otomatik yüklenir
2. API Anahtarı Oluşturma
Profil menüsünden API Management bölümüne gidin
Create API butonuna tıklayın
Enable Futures iznini aktif edin
API Key ve Secret Key değerlerini kopyalayın
3. Bağlantı
Anahtarları sağ taraftaki forma yapıştırın
Kaydet ve Doğrula butonuna tıklayın
Sistem otomatik olarak bağlantıyı kurar
Önemli Bilgi
Bu bir test ortamıdır. Gerçek para kullanılmaz. Tüm işlemler sanal bakiye ile yapılır.

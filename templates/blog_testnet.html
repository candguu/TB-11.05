Testnet Nedir ve Neden Önemli?

Binance Futures Testnet, gerçek piyasa verilerini kullanarak ancak sahte para ile işlem yapmanızı sağlayan bir test ortamıdır. Bu sayede stratejilerinizi gerçek para kaybetme riski olmadan test edebilirsiniz.

💡 Önemli: Testnet'te yaptığınız işlemler gerçek değildir, ancak piyasa verileri canlı verilerle aynıdır.

Testnet Hesabı Oluşturma

Binance Futures Testnet'e erişim için ayrı bir hesap oluşturmanız gerekir:

Adımlar:
1. demo.binance.com adresine gidin
2. "Register" butonuna tıklayın
3. E-posta ile kayıt olun
4. E-posta doğrulamasını tamamlayın
5. Giriş yapın ve test bakiyenizi alın

Test API Anahtarı Oluşturma

Bot geliştirmek için Testnet API anahtarı oluşturun:

  • Testnet hesabınıza giriş yapın
  • API Management bölümüne gidin
  • Yeni API anahtarı oluşturun
  • Futures trading iznini aktifleştirin

Python Bot Konfigürasyonu

Botunuzu Testnet'e bağlamak için endpoint'leri değiştirin:

from binance.client import Client

# Testnet konfigürasyonu
client = Client(
    api_key='your_testnet_api_key',
    api_secret='your_testnet_secret',
    testnet=True  # Bu parametre önemli!
)

# Testnet endpoint'leri
# REST API: https://demo.binance.com
# WebSocket: wss://stream.binancefuture.com

Test Bakiyesi Alma

Testnet'te işlem yapmak için test bakiyesi almanız gerekir:

  • Testnet arayüzünde "Get Test Funds" butonuna tıklayın
  • 10,000 USDT test bakiyesi alın
  • Bakiye biterse tekrar alabilirsiniz
  • Test bakiyesi gerçek değildir

Bot Test Stratejisi

Testnet'te botunuzu sistematik olarak test edin:

Test Aşamaları:

  • 1. Bağlantı Testi: API bağlantısını kontrol edin
  • 2. Veri Çekme: Market data alımını test edin
  • 3. Küçük İşlemler: Minimal pozisyonlarla başlayın
  • 4. Strateji Testi: Tam stratejinizi çalıştırın
  • 5. Performans Analizi: Sonuçları değerlendirin

Testnet Sınırlamaları

Testnet kullanırken dikkat edilmesi gereken noktalar:

  • Likidite Farkı: Testnet'te likidite mainnet'ten farklı olabilir
  • Slippage: Gerçek piyasada slippage daha yüksek olabilir
  • Psikolojik Faktör: Gerçek para olmadığı için duygusal tepkiler farklıdır
  • Network Latency: Testnet bazen daha yavaş olabilir
⚠️ Uyarı: Testnet'te başarılı olan bir strateji mainnet'te farklı sonuçlar verebilir. Gerçek ortama geçerken küçük pozisyonlarla başlayın.

Mainnet'e Geçiş

Testnet'te yeterince test ettikten sonra gerçek ortama geçiş yapın:

  • Gerçek Binance hesabında API anahtarı oluşturun
  • Bot kodunda testnet=False yapın
  • Küçük pozisyonlarla başlayın
  • Performansı yakından takip edin

Sonuç

Testnet, bot geliştirme sürecinin vazgeçilmez bir parçasıdır. Gerçek para kaybetmeden stratejilerinizi test etmenizi sağlar. Ancak testnet'teki başarının mainnet'te de devam edeceğini garanti etmez - her zaman dikkatli olun.

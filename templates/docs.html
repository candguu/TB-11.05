TB Trading Bot kullanım kılavuzu

Hızlı Başlangıç

TB Trading Bot, Binance API ile entegre otomatik trading botu. Futures işlemlerinde OTT stratejisi kullanır.

1. Hesap Oluştur

Sisteme kayıt olun ve email doğrulamasını tamamlayın.

2. API

Binance API anahtarlarınızı güvenli şekilde entegre edin.

3. Bot Aktifleştir

Strateji seçin ve botu aktif hale getirin.

Kurulum Adımları

Binance API Kurulumu

  1. Binance > API Management > Create API
  2. Sadece "Enable Futures" seçeneğini işaretleyin
  3. "Enable Withdrawals" seçeneğini ASLA işaretlemeyin
  4. API Key ve Secret Key'i kaydedin

Bot Kurulumu

  1. Dashboard > API sekmesine gidin
  2. API anahtarlarınızı yapıştırın
  3. "Test Connection" ile bağlantıyı doğrulayın
  4. Bot Paneli'nden strateji seçin ve aktifleştirin

Sık Sorulan Sorular

Bot güvenli mi?

▼

Evet, API anahtarınızda sadece "Futures Trading" yetkisi olmalı. "Withdrawal" yetkisi verilmemelidir.

Minimum yatırım miktarı?

▼

Alt limit yoktur - Binance'ın izin verdiği en düşük bakiye kadar (yaklaşık $10-20 USDT) başlayabilirsiniz. Risk yönetimi için $100+ önerilir.

7/24 çalışır mı?

▼

Evet, bot cloud sunucularımızda kesintisiz çalışır.
